## 关于我

我是一名独立开发者与开源项目维护者，长期关注 **自托管基础设施、本地模型部署、知识工具和可持续维护的软件系统**。

我更在意一个项目是否能够被部署、复现和长期维护，以及使用者能否清楚理解它的能力、限制与运行方式。

## 精选项目

| 项目 | 核心价值 | 主要能力 |
|---|---|---|
| **[Puppy Stardew Server](https://github.com/AmigaMeow/puppy-stardew-server)** | 让多人游戏主机可以长期、可重复地部署和维护 | Docker 服务、Web 管理、存档与备份 |

## 工程方向

- **本地模型与工具链**：量化、下载、推理运行、模型接入与部署说明。
- **自托管与基础设施**：Docker、Linux、服务编排、数据持久化与运行维护。
- **知识与内容系统**：检索、引用、内容审核、版本管理与可信阅读体验。

## 工作原则

- **先解决真实问题**：不为展示而堆功能，优先完成可使用的闭环。
- **部署也是工程的一部分**：安装、配置、升级和故障恢复都需要被设计。
- **公开真实边界**：明确项目适用范围、已知限制与维护状态。
- **文档降低试错成本**：让使用者能够理解、复现并继续维护项目。
