## 我在做什么

我关注的不是“再做一个 AI Demo”，而是把模型、基础设施和产品体验真正连接起来：

- **AI 产品工程**：模型接入、API 网关、工具调用与可用的用户界面
- **本地推理与自托管**：模型量化、部署路径、硬件边界与运维体验
- **开源产品化**：让项目具备清晰文档、可复现部署和长期维护能力
- **知识与阅读系统**：让检索、引用和内容边界更可靠

## 代表项目

### [Puppy Stardew Server](https://github.com/AmigaMeow/puppy-stardew-server)

将《星露谷物语》多人主机封装为可持续运行的 Docker 服务，提供一键部署、Web 管理面板、存档管理、备份恢复和 Mod 工作流。

`Docker` `Shell` `Web Panel` `Self-hosted`

### [观自在 · Guanzizai](https://github.com/AmigaMeow/guanzizai)

面向古籍与公共领域文本的现代阅读软件，强调原文优先、出处可核验、内容有边界，并覆盖阅读、检索、书房和引用式问答流程。

`Next.js` `React` `TypeScript` `PostgreSQL`

### [Kimi K3 Local](https://github.com/AmigaMeow/kimi-k3-local)

Kimi K3 本地量化部署手册，整理国内镜像、14 个 GGUF 分片直链、量化版本、硬件要求和运行路径。

`Local AI` `GGUF` `llama.cpp` `macOS`

## 我重视的事情

- 项目必须能部署、能维护，而不只是截图好看
- 文档应该减少用户试错，而不是制造更多概念
- AI 输出需要来源、边界和可核验性
- 开源项目应明确说明适用场景与真实限制
