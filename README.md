## 工程原则

- **先解决真实问题**：不为展示而堆功能，优先完成可使用的闭环。
- **部署也是产品的一部分**：安装、配置、升级和故障恢复都应被认真设计。
- **公开真实边界**：明确项目适用范围、已知限制与维护状态。
- **文档降低试错成本**：让用户能够理解、复现并继续维护项目。
