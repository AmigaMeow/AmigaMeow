## 关于我

我是一名独立开发者，主要构建 **AI 产品、自托管系统和可持续维护的开源工具**。

我更关注完整交付，而不只是功能演示：从模型接入、产品界面和部署方式，到文档、运维与真实使用边界。

## 工作方向

- **AI 产品工程**：模型 API、工具调用、用户界面与可落地的工作流。
- **自托管与基础设施**：Docker、Linux、本地推理、部署路径与运行维护。
- **知识与阅读系统**：检索、引用、内容审核与可信的阅读体验。

## 工程原则

- **先解决真实问题**：不为展示而堆功能，优先完成可使用的闭环。
- **部署也是产品的一部分**：安装、配置、升级和故障恢复都需要被设计。
- **公开真实边界**：明确项目适用范围、已知限制与维护状态。
- **文档降低试错成本**：让用户能够理解、复现并继续维护项目。
